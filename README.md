# CNN-CIFAR10-Vehicles-Animals
👤 Student ID: 210108
📖 Project Overview

This project implements a Convolutional Neural Network (CNN) using PyTorch to classify images from a subset of the CIFAR-10 dataset and evaluate the trained model on real-world smartphone images.

The model is trained on four object categories:
*Cat
*Dog
*Car
*Bird
After training, the model is tested using custom photos taken with a mobile phone, ensuring real-world applicability.
